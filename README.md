# VECTOR CRM

Первая рабочая версия CRM для автомобильного бизнеса.

## Уже работает
- карточка автомобиля;
- редактирование данных авто;
- клиент / покупатель;
- расходы;
- автоматический расчёт маржи;
- загрузка фото и документов;
- локальное хранение файлов в браузере через IndexedDB;
- открытие и удаление загруженных файлов;
- адаптивный интерфейс.

## Файлы
- `index.html` — интерфейс
- `styles.css` — оформление
- `app.js` — логика
- `vercel.json` — настройки публикации
- `.gitignore` — служебные исключения

## Публикация на Vercel
Это статический проект, сборка не нужна.

Рекомендуемые настройки:
- Framework Preset: Other
- Build Command: пусто
- Output Directory: пусто
- Root Directory: `./`

## Важно
Сейчас данные и документы хранятся локально в браузере конкретного устройства.
Следующий этап — подключение облачной базы и файлового хранилища.
