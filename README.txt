VECTOR CRM — готовая сборка

index.html — список автомобилей с поиском и показателями склада.
car.html — карточка выбранного автомобиля.
app.js — загрузка списка из Supabase и переход в карточку по id.
car.js — загрузка автомобиля, расходов и расчёт маржи.
styles.css — тёмный адаптивный интерфейс.
card.css — стили расширенной карточки.
setup-next-step.sql — создание таблиц и хранилища для фото, документов, маршрута и истории.

Откройте index.html через локальный сервер или разместите все файлы в одном репозитории.

Перед использованием новых функций один раз выполните setup-next-step.sql
в Supabase: SQL Editor → New query → Run.
